# Pizza Sales Exploratory Data Analysis using MySQL

## Project Overview
This project analyzes pizza sales data using SQL in MySQL Workbench.

The project focuses on:
- Revenue analysis
- Best selling pizzas
- Peak order timings
- Category performance
- Customer ordering behavior

---

## Tools Used
- MySQL Workbench 8.0 CE
- SQL

---

## Dataset Files
- orders.csv
- order_details.csv
- pizzas.csv
- pizza_types.csv

---

## SQL Concepts Used
- JOINS
- GROUP BY
- Aggregate Functions
- Window Functions
- CTEs
- Subqueries
- CASE Statements

---

## Key Business Questions Solved
- Which pizza generated highest revenue?
- Which pizza category performed best?
- What are the busiest hours?
- Which pizzas are ordered most frequently?
- What is the average order value?
